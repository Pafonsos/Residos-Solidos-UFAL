# Residos-Solidos-UFAL

Finalmente, chegamos ao precesso final da construção da aplicação.

A priori será definido a estipulações de versões prototipadas do projeto, focaremos em protótipos testáveis e incrementais, garantindo valor desde as primeiras versões até a consolidação do escopo completo.

Para isso vamos dividir o nosso projeto em duas frentes, o backend e o frontend.

| Frente | Especificações |

| FrontEnd | UI |
| BackEnd | Funções de Negócios |
| BackEnd | Banco de Dados |
